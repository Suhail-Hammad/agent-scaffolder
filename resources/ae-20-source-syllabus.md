## Course Information

## Course Description and Requisites

Introduction to the fundamentals of drafting and computer-aided design with applications in aircraft and spacecraft design.

Lecture 1 hour / Lab 3 hours. Letter Graded.

### Classroom Protocols

In the Lab you will need to have:
1. USB/flash drive
2. Headphones/Earbuds

## Course Goals

Introduce students to:
1. Technical freehand sketching.
2. Technical drawing.
3. 2D and 3D computer-aided design tools (CATIA, Inventor, or other CAD software available).

## Course Learning Outcomes (CLOs)

Students completing the course will be able to:
1. Freehand sketch a 3D view of an object (isometric, oblique and perspective).
2. Draw the standard 2D views (top, front and profile) of an object.
3. Apply simple and complex constrained 2D sketches to create solid features.
4. Construct 3D solid models from sketch geometry using extrusions, revolutions, and sweeps.
5. Create part features such as holes, shells, fillets, chamfers, threads and drafts.
6. Construct and annotate layout drawings.
7. Build basic 3D assemblies with assembly constraints.
8. Layout 3D exploded assembly drawings with balloon labels and a bill of materials parts list.

### Grading of CAD Files (rubric, 0–4 scale: F- / D- / C- / B- / A-)

**CAD models**
- F (0): Models missing or skipped entirely. No evidence of models in file.
- D (1): Models poorly created.
- C (2): Models adequately created but with some inaccuracies.
- B (3): Models adequately created.
- A (4): Models adequately created with work planes and sketches turned off. Also clean and named features in model tree with minimum features needed, and includes iProperties filled out (i.e. name, material, part number).

**CAD Drawings**
- F (0): No evidence of drawings or cannot open drawing file. No dimensioning.
- D (1): Drawings poorly created. No dimensioning.
- C (2): Drawings adequately created, with some dimensioning.
- B (3): Drawings adequately created, with dimensioning.
- A (4): Drawings adequately created, with correct dimensioning.

**CAD Assemblies**
- F (0): No evidence of assembly or cannot open assembly file.
- D (1): Assembly poorly created.
- C (2): Assembly adequately created, but with some inaccuracies.
- B (3): Assembly adequately created.
- A (4): Assembly adequately created with all parts and assemblies constrained properly.

**CAD Exploded view file (i.e. Inventor Presentation file)**
- F (0): No evidence of exploded view file or cannot open file.
- D (1): Exploded view poorly created.
- C (2): Exploded view adequately created, but with some inaccuracies.
- B (3): Exploded view adequately created.
- A (4): Exploded view adequately created with grouping, order of tweaks, and good spacing for animation.
